Powerful Elementor addon with customizable hero sliders, review carousels, and portfolio showcases featuring responsive design and smooth animations.

== Description ==

DailySlider is a powerful Elementor addon that adds feature-rich slider and carousel widgets to create stunning hero sections, testimonials, and portfolios with ease.

**DailySlider** is a versatile Elementor addon plugin that allows you to create stunning sliders, carousels, and showcases on your website. Whether you're looking to add a hero section, a testimonial carousel, or a portfolio gallery, DailySlider offers a set of highly customizable and responsive widgets that integrate seamlessly with Elementor. Enhance your website's visual appeal with smooth animations and engaging hover effects for a dynamic user experience.



### Key Features:
- **Fully responsive design** ensuring your sliders look great on all devices (desktop, tablet, mobile)
- **Pixel Widget (Hero Slider)**: Create full-screen, attention-grabbing hero sliders with cleaner Elementor control grouping and transition modes including Slide, Fade, Smooth Fade, Cube, Flip, and Coverflow.
- **Review Carousel Widget (Testimonial Carousel)**: Display customer reviews and testimonials in an interactive carousel format.
- **Eldorado Widget (Image Carousel)**: Showcase portfolio items or images in a stylish and sleek carousel layout.
- **Skyboot Portfolio Widget**: Filterable masonry/grid portfolio gallery with image, video, and external link items.
- **Marquee Slider Widget**: Create smooth scrolling marquee effects for displaying logos, testimonials, or any content in a continuous loop.
- **Customization options** for text, images, spacing, colors, and typography.
- **Lean frontend behavior** with simplified widget initialization logic to reduce bloat while preserving existing functionality.
- **Seamless integration with Elementor's drag-and-drop editor** for easy design.

This plugin is perfect for creating stunning sliders that elevate your website's aesthetic and functionality with minimal effort.

== Widgets ==

- **Pixel (Hero Slider)**
  - A full-screen hero slider widget designed to display your most important content in an eye-catching manner.
  - Ideal for showcasing high-quality images or videos with smooth animations.

- **Review Carousel (Testimonial Carousel)**
  - Display customer testimonials in a dynamic carousel layout.
  - Helps you highlight positive reviews and build trust with potential customers.

- **Eldorado (Image Carousel)**
  - An elegant image carousel widget designed for portfolio showcases, photography galleries, or any image-based content.

- **Marquee Slider**
  - A smooth scrolling marquee widget perfect for displaying logos, testimonials, announcements, or any content in a continuous loop.
  - Features customizable speed, direction, pause on hover, and edge masking effects.

- **Skyboot Portfolio**
  - A portfolio gallery widget with masonry/grid layouts, filter categories, lightbox support, and mixed media items.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/daily-slider` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Open the **Elementor Editor** and find the **DailySlider** widgets under the **Elementor Widgets** panel.
4. Drag and drop your desired widget (Pixel, Review Carousel, Eldorado, Marquee Slider, or Skyboot Portfolio) into your page and start customizing.

== Frequently Asked Questions ==

= Can I use these widgets on mobile devices? =
Yes, all widgets are **fully responsive** and optimized for mobile, tablet, and desktop devices. You can customize how they look on each device for a seamless experience.

= Does this plugin require Elementor? =
Yes, this plugin is an **Elementor extension** and works only with the **Elementor page builder**. Make sure Elementor is installed and activated before using this plugin.

= Can I customize the animations and effects? =
Yes, the plugin provides options to customize **animations**, **hover effects**, and **transitions** for all widgets, allowing you to create unique and interactive content.
